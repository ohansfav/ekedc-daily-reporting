# EKEDC Daily Reporting App

A simple cashier reporting dashboard for EKEDC daily and weekly data collection, review, and Excel export.

## Run locally

```bash
npm start
```

Then open: http://localhost:3000

## Deploy to Replit

1. Import this repo into Replit.
2. Make sure the Run command is:
   ```bash
   npm start
   ```
3. Replit will serve the app on the assigned port automatically.

## Features

- Staff login
- Cashier daily report form
- Preview and confirmation before submit
- Admin review dashboard
- Daily grouping and export to Excel
- Weekly summary export
- Local browser persistence with IndexedDB
